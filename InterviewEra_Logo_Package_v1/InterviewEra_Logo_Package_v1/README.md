# InterviewEra Logo Package v1

Approved direction: serif-style IE monogram with a purple/lilac sweeping stroke, white-first presentation, and the InterviewEra wordmark.

## Included
- Primary vertical logo
- Horizontal website header logo
- Stacked logo
- Square app/icon treatment
- Circular icon treatment
- Favicon PNGs: 16, 32, 48, 64, 128, 180, 192, 256, 512
- favicon.ico
- Social icon assets
- Black and gray monochrome references
- Purple icon reference
- Wordmark-only reference
- Approved logo-board source image
- Approximate web color references

## Website usage
- Navbar: `01-primary/interviewera-horizontal.png`
- Footer / brand section: `01-primary/interviewera-primary-vertical.png`
- Mobile / compact branding: `02-icons/interviewera-icon-square-white.png`
- Favicon: `03-favicon/favicon.ico`
- PWA icons: 192x192 and 512x512 PNGs
- Social profiles: `04-social/`

## Important production note
These assets are extracted and prepared from the approved rendered logo board. They are high-resolution raster deliverables. They are not mathematically redrawn vector artwork.

For a final production brand system, the IE monogram and wordmark should be recreated as true SVG/vector paths before large-scale print use or further logo modification.

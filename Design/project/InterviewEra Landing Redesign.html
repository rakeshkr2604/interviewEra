The shift

From random answers → structured answers that get shortlisted

Same question. Two ways to answer. Spot the difference in two seconds.

❌ Weak answer — unstructured
"Tell me about a time you solved a hard technical problem under a deadline."
"Yeah so basically in my project we had some issues and I worked with my team. We used different things and I did my best. It was tough but we managed to finish it. I learned a lot from the experience and I'm a quick learner so I can adapt."
✕ Sounds like every other candidate
✕ No proof of ownership or impact
✕ Panel can't score this → low shortlist odds
✅ Structured — STAR format
"Tell me about a time you solved a hard technical problem under a deadline."
Situation
Final-year project: payment API failing intermittently two days before submission — team of four, professor demo locked.
Task
I owned backend debugging and had to stabilise retries without breaking the existing checkout flow.
Action
Reproduced with logging, traced a race in the retry worker, added idempotent keys + backoff. Paired with frontend for error UX.
Result
Zero failed demos. Submission on time. Professor used it as the class example for error handling.
✓ Ownership clear ✓ Metric in result ✓ Scoreable by any panel

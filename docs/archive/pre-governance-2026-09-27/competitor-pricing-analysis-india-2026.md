## RECOMMENDATION

### **HYBRID PRICING — Best of All Worlds**

```
Free: 3 credits (₹0)
  → Gateway, no friction

Starter: ₹149/month, 8 sessions (₹18.62/session)
  → Entry point for price-sensitive students
  → "Try it seriously for less than ₹5/day"
  
Pro: ₹399/month, 25 sessions (₹15.96/session)
  → Best value (lowest per-session cost)
  → Serious users who want volume practice
  → Still 97% cheaper than human expert

Placement Season: ₹999 one-time, 90 days unlimited
  → High-intent users 2 months before placement
  → Alternative to ₹5,000-10,000 coaching
```

**Why this works:**

1. **Three price points = three user segments**
   - Starter: Curious/trying (Tier-3 students)
   - Pro: Serious prep (all colleges)
   - Placement Season: Urgent need (final year, interviews starting)

2. **Anchoring effect:** ₹999 one-time makes ₹399/month look like a bargain

3. **Volume pricing done right:** Pro has LOWEST per-session cost (₹15.96) — rewards serious users

4. **Still 95-97% cheaper than human experts** — massive moat
